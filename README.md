# ProSlide for Elementor

Advanced responsive Elementor slider plugin with full content design, background images & Ken Burns effects, Elementor template slides, and nested Elementor widget slides.

**Author:** Developer Hridoy  
**Requires at least:** WordPress 6.0  
**Tested up to:** WordPress 6.7  
**Elementor tested up to:** 3.26+  
**Requires PHP:** 7.4+  
**License:** GPL-2.0-or-later  

---

## Features

- **ProSlide Content & Template Slider:**
  - Full content design (Subtitle/Badge with icon, Title with tag selector, WYSIWYG Description, 2 CTA buttons).
  - Background image with size & position controls, plus **Ken Burns Zoom In/Out**.
  - Solid color & Gradient backgrounds with customizable overlay color/opacity.
  - Render any saved **Elementor Template** as a slide, or mix templates with content overlays.
  - Staggered active-slide entrance animations (`fadeInUp`, `fadeInDown`, `fadeInLeft`, `fadeInRight`, `zoomIn`).
  - Glassmorphism content box with backdrop-filter blur, border radius, and box shadows.

- **ProSlide Nested Widget Slider:**
  - Supports Elementor's **Nested Elements** architecture to drag and drop **any Elementor widget** directly inside each slide.
  - Per-slide background styling and overlay controls.

- **Responsive & Behavior Controls:**
  - Independent Desktop / Tablet / Mobile breakpoints for Slides Per View, Slides to Scroll, and Space Between.
  - Transition effects: `Slide`, `Fade`, `Coverflow`, `Flip`, `Cube`, `Cards`.
  - Infinite Loop, Autoplay with delay & pause on hover/interaction, Keyboard & Mousewheel navigation, Centered slides, Auto height.
  - Flexible Navigation Arrows (inside/outside/bottom-right/etc.) & Pagination (bullets, fraction, progress bar).

## Installation

1. Download [`proslide-elementor.zip`](./proslide-elementor.zip) from this repository.
2. In your WordPress Admin, go to **Plugins > Add New > Upload Plugin**.
3. Choose `proslide-elementor.zip` and click **Install Now**.
4. Click **Activate Plugin**.
5. Edit any page with **Elementor** and find the **ProSlide Elements** category in the widget panel.

*(Optional)* To use the Nested Widget Slider, ensure **Nested Elements** is active under **Elementor > Settings > Features**.
