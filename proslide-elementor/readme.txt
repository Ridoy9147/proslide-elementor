Advanced responsive Elementor slider plugin with full content design, background images & Ken Burns effects, and Elementor template slides.

== Description ==

ProSlide for Elementor adds the **ProSlide Content & Template Slider** widget under the **ProSlide Elements** category in Elementor:

- **Full Content Design**: Subtitle/badge with icon, Main Title (customizable HTML tag), Rich WYSIWYG Description, Primary & Secondary CTA Buttons with icons.
- **Per-Slide Background**: Background Image (Size, Position, Ken Burns Zoom In/Out), Solid Color, Gradient, and Overlay Color.
- **Elementor Template Slides**: Use any saved Elementor Template (`elementor_library`) as a slide, or combine an Elementor Template with an overlay content box.
- **Content Entrance Animations**: Fade In Up/Down/Left/Right and Zoom In with staggered delays and custom duration.
- **Global & Per-Slide Style Controls**: Configure design globally from the Style tab, or override specific slide typography, colors, padding, and buttons per slide.
- **Detailed Responsive Controls**: Independent Desktop, Tablet, and Mobile settings for Slides Per View, Slides to Scroll, Space Between, Slider Height, Typography, Padding, and Arrow visibility.

== Installation ==

1. Upload the `proslide-elementor` folder to `/wp-content/plugins/` or install the ZIP file via **Plugins > Add New > Upload Plugin**.
2. Activate **ProSlide for Elementor** in WordPress.
3. Open any page with **Elementor** and search for **ProSlide** in the widget panel.
